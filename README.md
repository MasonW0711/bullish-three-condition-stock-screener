# 紅黑線多空雙向突破回測選股系統

> **聲明：本工具僅供研究與篩選參考，不構成任何投資建議。**

## 系統目標

依方向（做多／做空）分流，找出符合下列任一**訊號路徑**的股票：

| 路徑 | 方向 | 路徑歸屬 | 觸發 | 回測判定 |
|------|------|------|------|----------|
| P1 突破回測 | 做多 | 突破回測路徑 | 向上突破紅線或黑線（收盤確認，由下往上） | 突破後窗格內、由上往下測線並守在線上，開盤不能跳過線超過容許度 |
| P2 新線回測 | 做多 | 新線路徑 | 新紅線出現（不需突破） | 新紅線觀察窗內、由上往下測線並守在線上，開盤條件同上 |
| P3 跌破回測 | 做空 | 突破回測路徑 | 向下跌破紅線或黑線（收盤確認，由上往下） | 跌破後窗格內、由下往上測線並壓在線下，開盤不能跳過線超過容許度 |
| P4 新線回測 | 做空 | 新線路徑 | 新黑線出現（不需突破） | 新黑線觀察窗內、由下往上測線並壓在線下，開盤條件同上 |

**新線路徑（P2／P4）的方向由新線的顏色決定**：新紅線只找做多（守住），新黑線只找做空（壓回）。**突破回測路徑（P1／P3）的方向則由突破／跌破方向決定**，與線的顏色無關；紅線、黑線都可能被向上突破或向下跌破。一根 K 棒可同時符合多條路徑，會依方向分流為多列輸出；每筆訊號出現後，只要之後有任何一根收盤破線，就會從訊號表和最新摘要移除（見下方「訊號後破線」）。

**回測判定（v4）**：做多是「由下往上突破、收盤高於線」，之後「由上往下回測、收盤守在線上」；做空為完全相反。程式上以四個條件落實：回測棒的**前一根收盤**在線的正確一側（做多在線上、做空在線下）、回測棒與突破棒**必須不同根**（突破當根不算回測）、回測須在突破後 `retest_window` 根 K 棒內發生（新線路徑則是出現後 `new_line_window` 根，紅黑各自獨立計算），且窗格內一旦收盤穿回基準線即**提前失效**；再加上 v4 新增的第五個條件——回測棒**開盤不能跳過線超過「開盤穿線容許度」**（預設 1%，可調），跳過視為穿線而非測試，但不會讓窗格失效（只有收盤破線才會）。此外，v4 起**任一路徑的訊號，只要之後有一根收盤破線，就會從訊號表移除**，不受觀察窗或回看根數限制。

流程：

1. 下載日 OHLCV 資料。
2. 依使用者選擇轉成 Daily K / Weekly K / Monthly K。
3. 用前一根收盤價計算大紅攻與大黑攻。
4. 大紅攻成功產生紅線，大黑攻成功產生黑線，分別逐股往後延伸，並標記「新線出現」。
5. 偵測收盤價嚴格向上突破與向下跌破最新紅線或黑線（同根同時突破雙線時，做多取較高線、做空取較低線為回測基準）。
6. 以突破／跌破事件凍結基準線，在 `retest_window` 根窗格內偵測做多守住（P1）與做空壓回（P3），含方向前提、開盤條件與提前失效；另外新紅線在各自的 `new_line_window` 根窗格內偵測做多守住（P2），新黑線在各自的 `new_line_window` 根窗格內偵測做空壓回（P4），紅黑兩色互不影響。
7. 排除任一路徑中「之後有收盤破線」的訊號（訊號後破線），四條路徑皆適用。
8. 套用最近 N 根 K 棒、成交量與可選法人連續買賣超／賣超條件（連買用於做多、連賣用於做空），再依方向與路徑分流。

## 策略定義

攻擊方向只由 `Open` 與 `prev_close` 決定；`Close` 只決定攻擊成功或失敗。

| 訊號 | 條件 | 說明 |
|------|------|------|
| 大紅攻成功 | `Open > prev_close` 且 `Close > prev_close` | 產生紅線，紅線價格為 `prev_close` |
| 大紅攻失敗 | `Open > prev_close` 且 `Close < prev_close` | 不產生黑線 |
| 大黑攻成功 | `Open < prev_close` 且 `Close < prev_close` | 產生黑線，黑線價格為 `prev_close` |
| 大黑攻失敗 | `Open < prev_close` 且 `Close > prev_close` | 不產生紅線 |

向上突破條件（做多 P1 觸發）：

```text
previous Close <= previous line
current Close > current line
```

向下跌破條件（做空 P3 觸發）：

```text
previous Close >= previous line
current Close < current line
```

`previous Close` 等於線價時歸類為突破、不歸跌破。

做多回測（由上往下守住，P1／P2）：

```text
前一根 Close >= 回測線價                        # 由上往下：進入回測棒前收盤在線上
Low <= 回測線價                                # 當根測到線
Close >= 回測線價                              # 當根收盤守住
Open >= 回測線價 × (1 − 開盤穿線容許度)          # 開盤沒有跳過線超過容許度（v4）
```

做空回測（由下往上壓回，P3／P4）：

```text
前一根 Close <= 回測線價                        # 由下往上：進入回測棒前收盤在線下
High >= 回測線價                               # 當根測到線
Close <= 回測線價                              # 當根收盤壓回
Open <= 回測線價 × (1 + 開盤穿線容許度)          # 開盤沒有跳過線超過容許度（v4）
```

P1／P3 的基準線為「最新被突破／跌破的線」，回測有效範圍為事件後 `retest_window` 根（不含事件當根）；窗格內任一根收盤穿回基準線（做多 `Close < 線`、做空 `Close > 線`）即提前失效。P2／P4 的基準線分別是「目前的新紅線」與「目前的新黑線」——**v4 起兩者各自獨立**：新紅線只找 P2、新黑線只找 P4，同色之間只看最新一條，另一色的新線不影響對方的窗格；僅在出現後 `new_line_window` 根 K 棒內（不含出現當根）有效，且自 v3.3.0 起、v4 沿用**兩側各自也有提前失效**（新紅線窗內遇 `Close < 線` 作廢 P2、新黑線窗內遇 `Close > 線` 作廢 P4，互不影響；掃描不含新線出現當根）。

上面的「開盤穿線容許度」條件四條路徑共用：只影響一根 K 棒算不算「測到線」，**不影響窗格是否失效**——讓窗格失效的仍然只有收盤穿回基準線。**訊號後破線（v4 新增）**：任一路徑的訊號出現之後，只要該股後續有任何一根收盤破線（做多看收盤是否低於訊號用的線、做空看是否高於），這筆訊號就會從結果移除，不受觀察窗或回看根數限制。所有窗格一律以所選週期的 K 棒（根）計數，不以日曆交易日計。

## 功能

- 自動抓取 TWSE 上市與上櫃普通股清單，也支援手動輸入或上傳股票清單。
- 支援 Daily K / Weekly K / Monthly K。
- 多空雙向四條訊號路徑（P1～P4），分屬「新線路徑」（P2／P4，主要依據）與「突破回測路徑」（P1／P3，次要參考）；可用方向過濾只看做多或只看做空，也可用結果頁的路徑篩選器只看其中一種路徑。
- 可設定最近回看 K 棒數、最小成交量、突破回測窗格、新線回測窗格，以及**開盤穿線容許度**（回測棒開盤跳過線超過此百分比視為穿線而非測試）。
- 任一路徑的訊號，只要之後有一根收盤破線即從結果移除（訊號後破線），不受觀察窗或回看根數限制。
- 法人條件：外資 / 投信最近 N 日連續買超（用於做多）或連續賣超（用於做空）。
- Plotly K 線圖顯示紅線、黑線、突破／跌破標記、回測守住／壓回標記，以及新線路徑的守住／壓回標記（星形，滑鼠提示會顯示該訊號實際採用的線價）。
- 另畫出**凍結的回測基準線 `L`**（做多紫色、做空青色實線），僅在窗格存活期間出現。虛線的紅／黑線是「會移動的當前線價」，實線的凍結 `L` 才是訊號實際的判定依據——線價在窗格中途被新攻擊移走時兩者會分岔，此時合法訊號棒可能整根位於虛線之下。
- Streamlit 以「做多」「做空」分頁分開呈現結果與各自 K 線圖，分頁上方共用同一個**路徑篩選器**（全部／新線路徑／突破回測路徑，預設全部），同時作用於訊號表、最新摘要與可選股票的 K 線圖清單。
- 做多、做空訊號表與最新摘要皆有「路徑」欄；最新摘要改為每個方向內，每個（股票、路徑）組合各取最新一筆。
- Excel 匯出 `All_Data`、`Long_Signals`、`Short_Signals`、`Latest_Summary_Long`、`Latest_Summary_Short`、`Failed_Downloads`、`Parameter_Settings`（訊號表與摘要工作表皆含路徑欄；CSV／Excel 匯出不套用結果頁的路徑篩選器，一律輸出全部路徑）。


## 桌面執行檔（免 Python）

### 直接使用已封裝版本

- **Windows x64**：下載 `BullishThreeConditionStockScreener-windows-x64.zip`，解壓縮後執行資料夾中的 `BullishThreeConditionStockScreener.exe`。
- **macOS（Apple Silicon）**：下載 `BullishThreeConditionStockScreener-macos-apple-silicon.zip`，解壓縮後執行 `BullishThreeConditionStockScreener.app`。
  - macOS **Intel 不提供**封裝版（v3.2.3 起明確標示；該版本實際上從未成功建置過，先前的說明有誤）。Intel Mac 請改用下方「本機執行」或雲端版。
- 執行檔會自動在本機啟動 Streamlit，並開啟預設瀏覽器。
- **Windows** 若要結束程式，請直接關閉啟動時一起打開的命令視窗；**macOS** 可直接結束 `BullishThreeConditionStockScreener.app`。

> macOS 與 Windows 的封裝檔都不需要另外安裝 Python，但第一次執行未簽章程式時，系統可能會要求手動允許開啟。

### 本機打包

```bash
python -m pip install -r requirements.txt -r requirements-build.txt
python scripts/build_desktop.py
```

打包完成後的產物位置：

- **Windows**：`dist/BullishThreeConditionStockScreener/BullishThreeConditionStockScreener.exe`
- **macOS**：`dist/BullishThreeConditionStockScreener.app`

### GitHub Actions 自動打包

- Workflow 檔案：`.github/workflows/build-desktop-executables.yml`
- 在 GitHub Actions 手動執行 **Build desktop executables**，即可產生 Windows / macOS 下載檔。
- 推送 `v*` 標籤時，workflow 會同時上傳 artifacts，並把 zip 檔附加到 GitHub Release。

## 週 K / 月 K

週 K / 月 K 由日線資料重新取樣產生：

| 欄位 | 計算方式 |
|------|----------|
| Open | 期間第一個交易日開盤 |
| High | 期間最高價 |
| Low | 期間最低價 |
| Close | 期間最後一個交易日收盤 |
| Volume | 期間成交量加總 |
| Date | 期間最後一個實際交易日 |
